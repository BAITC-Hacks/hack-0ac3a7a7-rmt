## Проверка интерфейса вручную

- Досье: победившая и альтернативная роли, реальные значения, вклады, близость гипотез, следующий шаг.
- Дневная диаграмма и таблица совпадений для `100000003684369100`: 3 458 128 KZT, 89,9% наблюдаемого входа; предупреждение о неполноте входа seed.
- Цепочки из 2 и 4 переходов: стрелки не перекрываются узлами, на карте видны суммы и число операций. Таблица содержит полные GID.
- Для `100000008175078100` показано предупреждение о depth=4 и неподтверждённой терминальности.
- Мобильный viewport 390×844: горизонтального переполнения страницы нет; вкладки и широкие таблицы прокручиваются внутри своих контейнеров. После проверки размер сброшен.
- Смена клиента обновляет досье; ответы предыдущего запроса отменяются/отбрасываются по версии и GID.
- В журнале браузера после проверенных сценариев ошибок JavaScript не обнаружено.
- `node --check ui/app.js` и `git diff --check` прошли.

## Как повторить

Дополнительная репетиция инструкции README: исходники, `data/`, `ui/` и `tests/` скопированы в отдельную папку без готовых `out/`, `.runtime/` и `.venv/`. Создан новый venv; выполнен именно `python run.py` с установкой зависимостей, а не только `starter.py`. Все три CSV созданы и прошли проверку. Сервер копии запущен с `--use-prebuilt --port 8188`; `verify_mvp.py --server http://127.0.0.1:8188` подтвердил совпадение CSV и шести досье с результатами этой копии. Аналитический этап — 3,325 с; это не время установки пакетов. После проверки временный сервер остановлен, основной сервер на 8000 не затронут. Репетиция по-прежнему выполнена на том же Windows-компьютере, не на машине организаторов.

```powershell
python run.py --skip-install
python -m unittest discover -s tests -v
python verify_mvp.py
```

При запущенном сервере с исходным датасетом:

```powershell
python verify_mvp.py --server http://127.0.0.1:8000
```

## Что не заявляется как проверенное

- Live-запрос OpenAI: ключ не настроен в процессе сервера, работает локальный обработчик. Контракт и обработка ошибок API проверены моками, доступность реальной модели — нет.
- Нет размеченных правильных ролей: accuracy, precision/recall и «100% правильность» не измерялись. Роли — эвристические гипотезы.
- Тесты чистого окружения выполнялись на этом же компьютере, не на отдельной машине и не на всех ОС/версиях Python.
- Нет доказательства сквозного перемещения одной суммы, реальной принадлежности клиентов группе или виновности.
- Нет промышленной многопользовательской эксплуатации, долговременного нагрузочного теста или гарантии отсутствия всех ошибок. Это локальный хакатонный MVP.
- Опциональный стресс-тест удаления TOP-N узлов, обучение ML и онлайн-поток не реализованы. Чувствительность весов — другая, явно обозначенная проверка.
